# Tickwire Architecture and Specifications

Tickwire's specifications define the exact ownership boundaries, state machines, wire layouts, thread-affinity and spinlock invariants, resource bounds, and failure semantics enforced across the 42-crate Rust workspace. Every observable transition has a single state owner or fine-grained lock domain, a machine-verifiable encoding where data crosses processes, and deterministic tests plus finite-state and symbolic [TLA+ models](../tla/README.md) (TLC and Apalache).

## Pure Stateless 3-Process SHM Topology

Production deployments execute as three stateless Linux process roles communicating exclusively over `memfd`-sealed shared memory and authenticated Unix control sockets—with **zero local WAL, journal, disk blob files, HA-lease files, or runtime configuration patches**:

1. **`tickwire-md` (Market-Data Publisher):** Sole owner of public exchange feeds, sequence continuity, and `memfd` broadcast rings, with optional hot `reactor_cpu` pinning, cold background `housekeeping_cpus` (`md-cold`) pinning, and a bounded in-memory JOIN idempotency table.
2. **`tickwire-strategy-worker` / `tickwire-strategy-sdk` (Strategy Workers):** Read `tickwire-md` SHM rings at independent cursors and exchange inline `IntentRecord` (`1024B`) and `ReportRecord` (`512B`) slots over SHM rings with the ORS execution process (zero disk queues or disk blob files, optional `worker_cpu` + `housekeeping_cpus`).
3. **Unified ORS Execution Process (`1 ORS = 1 Venue`):** Zero public market-data connections or SHM quote subscriptions; manages `1..N` `AccountSession`s (`account_ref = 1..255`, `0` = first authorized account; `1 AccountSession = 1 Exchange UID`) across multi-product connection pools (`OrderRoute.product_mask`), multi-wallet / Unified Trading Account `AssetKey { wallet_id, asset_id }`, a shared process-wide atomic IP/account `SharedRateLimiter` (`RateLimiter`), and per-account `OrsQueryDesk`. Cold startup and restarts recover exclusively from static startup configuration plus authenticated Exchange REST snapshots (`Account + OpenOrders` and `Positions`) and 32-character `[0-9a-z]` `SelfDescribingClientId` (`tw1...` with domain-keyed MAC). Dedicated hot `REQ` (`req_cpu`) and `RESP` (`resp_cpu`, `epoll_wait_ms = 0` configurable) threads are strictly isolated from `housekeeping_cpus` (`Dialer`, `AsyncRestQuerier`/`OrsQueryDesk`, `LatencyTracer` sink, `ControlServer`, `main` `SignalWaiter`) via `tickwire-config` and `tickwire-control-sys` (`sched_setaffinity` + `sched_getaffinity` read-back verification, `hot_cpus ∩ housekeeping_cpus == ∅`), using non-overlapping fine-grained spinlocks (`LockedConnection`, `LockedOrder`, `OrsStpBook`/`StpBook`, `GuardedValue` `listenKey`) with zero logging, allocation, or parsing under lock.

## Specification Layers

* **[Module Contracts (`specs/implementation/`)](implementation/README.md)** — Complete catalog of all 53 implementation contracts organized by architectural layer and maintained in strict Code-Doc Lockstep with crate `AGENTS.md` files and rustdocs.
* **[Machine Schemas & Golden Vectors (`specs/contracts/`)](contracts/README.md)** — Language-independent JSON definitions and test vectors for inline SHM IPC wire framing (`48` layouts, `37` data message IDs, `38` control opcodes, `86` golden vectors), fixed-point risk math, instrument catalogs, and static deployment configurations.
* **[Formal Verification (`tla/`)](../tla/README.md)** — `21` model families (`40` TLC 2.19 finite-state models and `11` Apalache 0.63.0 Snowcat symbolic `IndInv` models) anchored via `anchors.lock` SHA-256 digests to core crate source lines (see the [Model Roadmap](../tla/ROADMAP.md)).
* **[Verification Commands (`scripts/`)](../scripts/README.md)** — Commands to run the 42-crate Rust test suite, Linux multi-process IPC and CPU-affinity checks, Python contract validators, and TLC/Apalache model runs.
* **Historical Acceptance Archives** — Point-in-time release verification bundles with byte-exact SHA-256 manifests from [October 28, 2026](evidence/20261028/README.md) and [October 29, 2026](evidence/20261029/README.md).
