# Nonblocking Transport, `LinkOps` Pools, `JsonScan`, `PublishedRoutes`, `LatencyTracer`, Dialer, and REST Querier

`tickwire-transport` (`#![forbid(unsafe_code)]`) provides explicitly driven nonblocking TCP and TLS streams built on `mio` `1.2.4` (`TCP_NODELAY` enabled) and `rustls` `0.23.46`, vtable-free multi-protocol execution links (`LinkOps`), zero-allocation single-pass JSON execution scanning (`JsonScan` / `MsgParser`), lock-free double-buffered route publication (`PublishedRoutes`), hardware `rdtsc` stage and spinlock contention tracing (`LatencyTracer`), and `housekeeping_cpus`-pinned background connection dialing (`Dialer`) and HTTP/1.1 REST reconciliation querying (`AsyncRestQuerier`). All OS socket-binding (`SO_BINDTODEVICE` / `local_ip`) and thread CPU-affinity operations delegate to [`tickwire-control-sys`](supervisor-process.md), and all hardware cycle-counter reads delegate to [`tickwire-clock-sys`](system-clock.md).

* **`connection` (`Connection`)**: Bounded nonblocking TCP/TLS stream (`Limits`, `IoBudget`) with `connect_from_with_nic` (`nic` `SO_BINDTODEVICE` taking precedence over `local_ip`), synchronous first-application-byte authorization (`try_send`), and hot-path atomic `send_frame_nonblocking` with immediate self-retirement upon any TCP or TLS partial/short write.
* **`json_scan` (`JsonScan`, `MsgParser`, `ScannedExecFrame`, `ScannedRateLimit`)**: Zero-allocation single-pass byte-slice scanner for Binance, OKX, and Bybit execution replies and private stream frames, extracting synonymous order IDs (`orderId`/`ordId`/`i`, `clientOrderId`/`origClientOrderId`/`clOrdId`/`orderLinkId`/`c`), status/execType, exact integer price ticks and quantity lots, fees, `rateLimits[]` counts/limits, `listenKey`/`urlToken` tokens, and venue error codes/messages with zero `Vec`/`String` allocations and zero `serde_json::Value` DOM trees.
* **`links` (`LinkOps`, `WsLink`, `HttpsLink`, `FixLink`, `GuardedValue`, `LockedConnection`, `UrlConnections`)**: Static-dispatch execution link state machines covering `WsLink` (`SendSlot::Shared`, `16` concurrent in-flight requests matched by `reply_id`, multi-step `loginChallenge` auth, and `early_frames` buffering/replay), `HttpsLink` (`SendSlot::Exclusive`, `1` in-flight keep-alive request), and lightweight `FixLink` (`Logon`, `Heartbeat`, `TestRequest`, sequence-gap `ResendRequest`, and `64`-slot `RefSeqNum -> RequestRef` `Reject` correlation), paired with per-connection `LockedConnection` spinlocks and multi-socket `[local_ip, count]` `UrlConnections` pools (`product_mask = 0` shared UTA pools for OKX/Bybit; per-market pools for Binance Spot/UM/CM/Options, with zero mutual exclusion between WebSocket and multi-connection pools).
* **`order_router` (`OrderRouter`, `PublishedRoutes`, `SampleMask`, `OrderConnectionPool`)**: Integer EWMA latency router (`9/8` hysteresis band `last_score * 8 <= best_score * 9`) fed by order RTTs, WebSocket Ping-Pong RTTs, application heartbeats, and `SampleKind::Tcping` active probes (`SampleMask`), plus double-buffered Acquire/Release `PublishedRoutes` snapshots so `REQ` selects ready `tickwire_venue::OrderRoute` entries without locks or allocations.
* **`dialer` (`IpPool`, `DialBaton`, `Dialer`)**: Dedicated `"tw-dialer"` thread spawned via `tickwire_control_sys::spawn_pinned_thread` onto `housekeeping_cpus` **before** `mio::Poll` creation, DNS resolution, TCP/TLS handshakes, WebSocket/FIX login handshakes, `GuardedValue` `listenKey`/`urlToken` reads, or active `Tcping` probes, handing ready `DialedLink`s to `RESP` via `DialBaton`.
* **`rest_querier` (`AsyncRestQuerier`)**: Dedicated `"tw-rest-query"` thread spawned via `spawn_pinned_thread` onto `housekeeping_cpus` **before** `mio::Poll` creation, heap buffer setup, DNS, or HTTPS I/O, driving keep-alive reconciliation queries (`Account + OpenOrders`, `listenKey`/`urlToken` lifecycle, and `QueryDesk` `StatusAsk`) over lock-free SPSC task and reply rings.
* **`latency_tracer` (`LatencyTracer`, `ThreadTracer`, `TimedSpinLock`)**: Zero-allocation `rdtsc` stage timestamping (`MarkSite`) and contended spinlock attribution (`LockWait` recording holder `ThreadTag`, waiter `ThreadTag`, `LockId`, and `wait_cycles`) over 32-byte atomic ring slots drained by a `"tw-latency-sink"` thread pinned to `housekeeping_cpus`.
* **`warmup` (`WarmupConfig`, `WarmupTracker`, `TlsLoopbackWarmer`)**: Side-effect-free idle-window TLS 1.3 and HTTP/WebSocket instruction/data cache warmer operating strictly on an isolated in-memory loopback pair without advancing live `Connection` TLS AEAD nonces.

## Limits, Budgets, Source Binding, and Subsystem Rules

Every `Limits` field (`max_send_bytes`, `max_receive_bytes`, `tls_buffer_bytes`, `max_accept_bytes`) and `PreparedSend` payload must be nonzero and `<= 16 MiB` (`HARD_LIMIT`; defaults: `1 MiB` send/receive, `16 KiB` TLS buffer and per-call accept chunk). `IoBudget` defaults to `8` syscalls and `65,536` network bytes per `drive` call.

| Boundary | Enforcement Rules |
| --- | --- |
| **TCP / TLS (`Connection`)** | `connect_from_with_nic(address, local_ip, nic, ...)` delegates to `tickwire_control_sys::open_bound_nonblocking_tcp_stream`: when `nic` is `Some(iface)`, `SO_BINDTODEVICE` takes precedence over `local_ip`; otherwise `local_ip` validates IPv4/IPv6 family agreement (`Error::Bounds` on mismatch) and binds `ip:0` with `SOCK_NONBLOCK \| SOCK_CLOEXEC` and `TCP_NODELAY`. Rejects TLS `0-RTT` (`enable_early_data`) with `Error::Protocol("early data disabled")`. On `send_frame_nonblocking`, any TCP partial write (`0 < n < len`), EOF, or TLS `write_tls` `WouldBlock`/EOF/error leaving `tls.wants_write() == true` immediately retires and shuts down the connection (`is_retired() == true`). |
| **Zero-Alloc Scanner (`json_scan`)** | Single forward pass bounded to `MAX_JSON_DEPTH` (`16`) stack frames and `MAX_SCANNED_RATE_LIMITS` (`8`) inline `rateLimits[]` entries; zero heap allocations (`Vec`, `String`, `Box`) and zero floating-point operations; scaled integers use checked `i128` fixed-point conversion. |
| **Links & Pools (`links`)** | `LinkOps` uses static enum dispatch (`WsLink`, `HttpsLink`, `FixLink`). `LockedConnection` holds its `TimedSpinLock` strictly across nonblocking socket/TLS byte writes (`REQ::send_frame`, `RESP` pong/heartbeat), raw receive drains (`poll_raw_rx`), and `Option<LinkOps>` swaps (`install`/`take`/`close_connection`)—never overlapping any `Order` lock and performing zero logging, zero heap allocation, and zero protocol parsing under the spinlock. Short writes latch `close_pending = true` and trigger `mio::Waker::wake()` (`eventfd`) outside the spinlock. `UrlConnections` expands `[local_ip, count]` pairs across WS, HTTPS, or FIX pools with `product_mask` routing (`0` universal UTA or per-product bitmask). |
| **HTTP/1.1, WS, FIX (`http`, `ws`, `fix`)** | HTTP/1.1 rejects CRLF injection, duplicate `Content-Length`, and ambiguous framing; WebSocket enforces RFC 6455 masking, minimal lengths, unfragmented control frames (`<= 125B`), and UTF-8 text; FIX validates `9=` (`BodyLength`) and modulo-256 `10=` (`CheckSum`). |
| **Pinned Dialer (`dialer`)** | `"tw-dialer"` binds `housekeeping_cpus` via `spawn_pinned_thread` before creating `mio::Poll` or performing DNS, TCP/TLS, WS HTTP `101` + `loginChallenge`, FIX `Logon`, or `Tcping` probes; reads dynamic `listenKey`/`urlToken` from `GuardedValue` off the hot path; preserves post-upgrade `early_frames` for replay upon authentication completion. |
| **Pinned REST Querier (`rest_querier`)** | `"tw-rest-query"` binds `housekeeping_cpus` via `spawn_pinned_thread` before `mio::Poll` or buffer setup; exchanges `RestTask` and `RestReply` over lock-free atomic SPSC rings while preserving the reply-slot reservation invariant `waiting.len() + usize::from(inflight.is_some()) + reply_queue.len() < capacity`. |
| **EWMA Router & Snapshot (`order_router`)** | `RouteHealth` folds `SampleMask`-enabled RTT samples (`SampleMask::IN_BAND` default: `Order \| Ping \| App`; `SampleMask::ALL` adds `Tcping`) in exact integer floor division `(ema_us * (ema_den - ema_new) + sample_us * ema_new) / ema_den`. `PublishedRoutes` publishes immutable snapshots across two atomic banks (`MAX_PUBLISHED_ROUTES = 64`) with `Release`/`Acquire` synchronization and `9/8` hysteresis (`last_score * 8 <= best_score * 9`). |
| **Hardware Tracer (`latency_tracer`)** | Hot threads write 32-byte atomic `TraceSlot` records (`rdtsc` stage marks and slow-path `TimedSpinLock` `LockWait` contention records) without blocking or allocating; `"tw-latency-sink"` binds `housekeeping_cpus` via `spawn_pinned_thread` and emits `StageBudgetExceeded`, `IterationSpike`, `LockContention`, and `QueueWrap` findings. |
| **Loopback TLS Warmer (`warmup`)** | `WarmupTracker` gates idle cycles via `checked_add` (`0` = disabled); `TlsLoopbackWarmer` exercises TLS 1.3 AEAD and HTTP/WS framing inside `[u8; 2048]` scratch buffers without touching live connections. |

## Core Invariants

* **Zero plaintext exposure & synchronous first-byte gate (`Connection`)**: `queue(prepared)` stages `SendState::Queued` (`accepted_bytes = 0`) without touching `rustls` or the socket. `try_send(now, authorize)` checks `deadline`, invokes `authorize()` synchronously immediately before the first byte write, re-checks `deadline` post-callback, and transitions to `MayHaveSent` if and only if `accepted_bytes > 0` (`Flushed` requires `accepted_bytes == total_bytes && !tls.wants_write()` and is recorded in `drive` before `read_tls`).
* **Immediate self-retirement on partial/short write**: On hot-path `LockedConnection::send_frame`, if TCP writes `0 < n < frame.len()` or TLS `write_tls` encounters `WouldBlock`/EOF/error while `tls.wants_write()` remains `true` after accepting plaintext into `rustls`, the connection immediately retires itself (`Shutdown::Both`), latches `close_pending`, and signals `RESP`'s `mio::Waker` (`eventfd`) after releasing the spinlock so a truncated frame or desynchronized TLS record never corrupts subsequent orders.
* **Lock hierarchy & spinlock purity**: `LockedConnection` and `GuardedValue` use pure userspace `try_lock` spin loops (`TimedSpinLock`) that never enter kernel futex wait queues and never overlap with any `Order` or `StpBook` spinlock. All protocol decoding (`ws::Decoder`, `http::ResponseDecoder`, `fix::Decoder`, `MsgParser::scan`), logging, and heap allocation occur strictly outside spinlocks.
* **Multi-step login & `early_frames` order preservation**: When a WebSocket venue pushes private frames during `AwaitingChallenge` or `AwaitingAuthAck` (or coalesced immediately after HTTP `101`), `WsLink` buffers them in bounded FIFO `early_frames` and replays them in exact arrival order upon `complete_login()` before new live frames.
* **Housekeeping CPU escape**: `"tw-dialer"`, `"tw-rest-query"`, and `"tw-latency-sink"` all invoke `tickwire_control_sys::spawn_pinned_thread(..., housekeeping_cpus, ...)` so even when the parent process is launched under a single-core `taskset`, background threads escape onto `housekeeping_cpus` (verified via `/proc/self/task/<tid>/status` `Cpus_allowed_list`) before allocating reactor state or performing I/O.
