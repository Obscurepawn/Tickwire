# IPC Wire Codec, Inline SHM ORS Records, DOP Logon Frames, and Zero-Copy Views

`tickwire-ipc` defines the fixed-layout ABI 1.0 binary representations and deterministic validation rules for control-plane frames (including Direct Order Entry Protocol / DOP logon sessions), pure in-memory inline shared-memory ring records (`MarketRecord`, `MarketExactRecord`, `IntentRecord`, `ReportRecord`, `OwnershipRecord`), optional shared-memory arena blocks for oversize payloads, immutable resource envelopes, and normalized market snapshots. Generated little-endian encoders and decoders operate exclusively on stable, caller-owned byte slices without runtime JSON dependencies, disk-backed blob files, heap allocation on hot record decode (`Record` uses stack-allocated variants while `ZeroCopyRecord` and `ZeroCopyIntentRecord` borrow 8-byte-aligned 512-byte and 1,024-byte SHM slots directly in place), or cryptographic signature verification.

The crate owns byte-level framing, field whitelists, hardware-accelerated Castagnoli CRC32C integrity primitives (`src/crc32c.rs`), `#[repr(C)]` zero-copy SHM record views (`src/zerocopy.rs`), and structural payload invariants. Crate-level `[lints.rust] unsafe_code = "deny"` and `#[forbid(unsafe_code)]` on every general codec module keep all non-audited code safe, isolating `#![deny(unsafe_op_in_unsafe_fn)]` strictly to `crc32c` and `zerocopy`. `tickwire-ipc` intentionally does *not* map or synchronize live shared-memory pages: reading a producer slot or shared cursor page while another process mutates it is undefined behavior, so callers must first establish slot stability and lifetime bounds using the acquire/release `RecordBorrow` protocol in `tickwire-shm-sys` and `tickwire-shm`. File-descriptor permissions, `memfd` seals, `SCM_RIGHTS` transfer, `SO_PEERCRED` peer identity, arena reuse watermarks, and trading risk grants remain enforced by their respective subsystem owners.

## State Model and Bounds

All wire structures enforce ABI `1.0`, exact byte lengths, zeroed reserved padding, zeroed inactive union branches, and sequence/generation numbers strictly below `2^63` (`Error::SequenceExhausted` at `>= 2^63`). Integrity digests use Castagnoli CRC32C (reflected polynomial `0x82f63b78`, initial value and final XOR `0xffffffff`) when `--features crc32` is enabled (default OFF on intra-host memory/socket paths), and SHA-256 for immutable resource descriptors and snapshot bundles.

## Core Invariants

* **Zero disk I/O on intent and report rings**: `IntentRecord` (`1,024` bytes) and `ReportRecord` (`512` bytes) carry single-order commands, cancellations, modifications, RFQ quotes, fills (including `amendment` fee adjustments), rate-limit warnings, and shutdown broadcasts completely inline inside the SHM ring slot. Oversize payloads (such as multi-leg lists or extended diagnostic blobs) bind an in-memory SHM Arena block (`payload_kind == 2`, `arena_offset == header.payload_offset >= 128`, `arena_len == header.payload_length`, `allocation_seq == header.sequence`) verified against `ArenaBlockHeader` without touching local filesystems.
* **Capability negotiation precedes body interpretation**: `ControlFrame::decode_negotiated` checks negotiated session feature bits before parsing gated extension opcodes—requiring feature bit 5 (`0x20`) for configuration-control opcodes `80..=84` and feature bit 10 (`0x400`, `DOP_PROTOCOL`) when negotiated gating is used on DOP opcodes `96..=100` (while `ControlFrame::decode` parses DOP frames directly on dedicated ORS UNIX domain sockets).
* **Lease non-extension**: Configuration and execution grant validators check roles, host boot ID, configuration revision/hash, and receipt bindings against caller-supplied identities, and guarantee that a valid execution lease can never extend an already expired risk grant.
* **Typed reply correlation on control transitions**: `QUIESCE` (opcode `20`) success replies (`flags == 10`) must carry `evidence_kind == 1` and a zero `exit_evidence_id`. `SWITCH` (opcode `19`) replies require zero `snapshot_id` and `snapshot_seq`, pairing `flags == 10` with `switch_kind == 2` and `flags == 18` with `status == 32` and `switch_kind == 3`.
* **Audited hardware CRC32C and zero-copy bit-validity (`src/crc32c.rs`, `src/zerocopy.rs`)**: `crc32c` dispatches to `x86_64` SSE4.2 (`_mm_crc32_u64` over `as_chunks::<8>()` + `u64::from_le_bytes`, zero pointer casts) or `aarch64` CRC (`__crc32cd` / `__crc32cb`), falling back to a compile-time `const TABLES: [[u32; 256]; 8]` Slicing-by-8 implementation (`crc32c_slicing8`), while `crc32c_masked` hashes masked header checksum ranges via zero-allocation `[0u8; 64]` chunks. Sealed `ZeroCopyRecord` (`MarketRecord`, `MarketExactRecord`, `ReportRecord` — 512 bytes, align 8) and `ZeroCopyIntentRecord` (`IntentRecord` — 1,024 bytes, align 8) contain exclusively primitive integers and fixed arrays (`u8`, `i8`, `u16`, `u32`, `i32`, `u64`, `i64`, `[T; N]`), enforced at compile time (`target_endian = "little"`, exact `size_of`, `align_of == 8`, and `offset_of!` for every field), and validate pointer alignment plus all semantic/reserved-padding rules before casting `*const u8` to `&Self`.

## Cost Accounting and Empirical Benchmarks

* **Startup vs. per-event cost**: Slicing-by-8 lookup tables (`8 KiB`) and layout assertions are resolved at compile time; CPU feature detection (`sse4.2` / `crc`) uses a cached atomic branch on first call; `ControlFrame` DOP logon (`DopLogin`, `DopEcho`, `OrsSessions`) runs only during session establishment or topology updates (plus periodic `DopHeartBeat`). On per-quote, per-order, and per-fill hot paths, `MarketRecord::from_aligned_bytes`, `IntentRecord::from_aligned_bytes`, and `ReportRecord::from_aligned_bytes` execute `0` heap allocations, `0` syscalls, `0` disk operations, `0` clock reads, `0` queue hops, and `0` 512-byte/1,024-byte stack struct materializations (`crc32 = OFF` also skips all CRC passes over ring slots).

## Operations and Failure Semantics

* **DOP logon and heartbeat lifecycle (opcodes `96..=100`)**: Strategy clients connect over UNIX domain control transport (`DopLogin`, `strat_id` `0..=254`, `next_source_seqnum`). The ORS gateway validates strategy exclusivity and sequence floors and replies with `DopEcho` (`next_source_order_seqnum = max(req.next_source_seqnum, ors_floor)`, `connected`, `enabled`, `market_connected`, `ready_to_trade = connected && enabled && market_connected`, `hb_interval_ms`, and TX/RX ring descriptors) plus `OrsSessions` (`MktSession` routing rows per `(account_ref, strat_id)`). Periodic `DopHeartBeat` frames carry `mono_ns` and `next_order_seqnum` so idle rings remain distinguishable from stalled peers; `DopLogout` cleanly tears down the session with optional cancel-on-logout semantics.
* **Resource offer and descriptor bounding (opcode `3`)**: `RESOURCE_OFFER` requires `1 <= descriptor_count == fd_count <= 16`, distinct `fd_index < descriptor_count` entries, and bounded `resource_kind` (`1..=9`), `access` (`1..=2`), and `seal_profile` (`1..=2`) codes.

python3 crates/tickwire-ipc/tools/generate.py wire
python3 crates/tickwire-ipc/tools/generate.py tests

The code generator embeds the SHA-256 digest of `ipc-wire-v1.json` directly into the generated Rust source so contract drift fails review and verification. Automated suites run generated field-offset/size layout tests (backed by compile-time `offset_of!` assertions), independent golden-vector tests (`ipc-vectors-v1.json`), differential HW-vs-Slicing-by-8 CRC32C tests across alignments `0..8` and lengths `0..=4,096`, and dedicated semantic suites covering both `crc32` feature modes, inline `IntentRecord` and `ReportRecord` zero-copy views, optional SHM Arena oversize validation, DOP logon frames, and exact-value market records.
