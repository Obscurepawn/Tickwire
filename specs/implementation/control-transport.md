# Linux control sockets and descriptor transfer

`tickwire-control-sys` uses Unix SEQPACKET sockets. A receive attempts one complete frame with space for 65,536 bytes and 16 file descriptors. Pass `MSG_DONTWAIT | MSG_CMSG_CLOEXEC` to recvmsg and align the ancillary buffer for usize. Take ownership of every delivered SCM_RIGHTS descriptor before validating truncation, length, indexes or counts. Any rejected frame then drops its local OwnedFd values. Continue collecting later rights even when an unknown cmsg invalidates the frame. Linux closes excess descriptors omitted under MSG_CTRUNC. `ReceivedFrame::into_parts` transfers the payload and descriptors to the caller.

Validate a send's structure and FD count before `sendmsg(MSG_DONTWAIT | MSG_NOSIGNAL)`. The sender retains ownership of its descriptors. A successful full datagram has reached the kernel. A partial result is truncation and must never be retried as a suffix. Blocking-style connect, accept, recv and send share an absolute Instant deadline. EINTR keeps that deadline, and EAGAIN polls for the remaining time.

For an event loop, `try_accept`, `try_recv` and `try_send` attempt one operation without polling, reading a deadline or sleeping. Empty accept/receive returns None, a full send queue returns false, and EINTR returns a system error. Queued messages drain before EOF. Asking a timed receive to wait one microsecond has different behavior because allocation and the deadline check precede recvmsg.

`PendingConnection` uses a nonblocking CLOEXEC socket. Retry connect itself after AF_UNIX backlog EAGAIN. EINPROGRESS/EALREADY uses zero-time readiness and SO_ERROR. Transfer the connection only after peer credentials are available. An exec'd child connects to the pathname so its PID/UID/GID can be matched to the live child handle. An inherited socketpair records its creator. Cross-process `monotonic_ns` comparisons require the same boot and time namespace. [connect(2)](https://man7.org/linux/man-pages/man2/connect.2.html) · [unix(7)](https://man7.org/linux/man-pages/man7/unix.7.html)

`PrivateDirectory::create_in` uses a random 128-bit suffix and mkdirat(0700) under a trusted parent. Bind relative to the opened parent through /proc/self/fd. Accept socket permissions 0600 or 0660 and check ownership. Pin the created inode using O_PATH, apply permissions to that inode, and compare the current name with the pinned inode before unlinkat on drop. The launcher serializes same-UID renames during cleanup.

The unsafe boundary covers libc calls, aligned output structs, ancillary parsing and creation of OwnedFd. Pointers refer to live buffers for the duration of a system call. Other platforms report UnsupportedPlatform. Linux tests exercise 0/1/16 descriptors, populated backlogs, malformed frames, FD cleanup, peer identity and EOF ordering.
