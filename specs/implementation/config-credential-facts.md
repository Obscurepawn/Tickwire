# 配置凭据元数据

接口见 配置凭据元数据核验。实现为 `tickwire-config-service::credential_facts`。

- 实际用途来自完整、私有构造的 `ProjectionSet`，保留全局候选摘要；每个投影的 process、host、OS 身份、用途、账户和固定 secret 引用均参与匹配。
- 目录由服务独立提供；每项先通过当前固定 issuer 的 `CredentialMetadata` 签名，再校验内容 scope、固定版本、非零 fingerprint、启用状态、观察新鲜度和严格字段集合。
- UID 取自受信签发者的授权映射，跨对象检查双向唯一性；没有将该检查描述为操作系统实际身份观测。
- 不同引用的执行/guardian 密钥别名在全目录上拒绝。额外合法 grant 不加入返回的使用集合。
- 返回对象字段私有，包含候选摘要、精确使用及完整验签结果。它不读取密钥，也不发放部署权限。

定向测试保留 真实 Red 和 Green。覆盖完整投影、精确主体匹配、目录缺失/重复/未知项、固定版本、观察时间、密钥别名、UID 冲突、额外 grant、严格内容、签名到期与服务观察期限。
