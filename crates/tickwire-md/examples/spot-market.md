# Share a public spot quote feed

The Bybit and OKX spot market owners each open one public WebSocket for a single symbol. The owner publishes the latest exact best bid and offer to one shared-memory topic. Each admitted strategy process reads that topic through its own cursor. Several strategies can observe the same feed without opening more venue connections.

## Launch the publisher and two workers

Run from the repository root on Linux with the pinned Rust toolchain, Python 3.11+, OpenSSL and binutils (`strip`).

```sh
python3 scripts/run-two-strategies.py --keep
```

This command builds the real publisher and registered counting worker, generates a private demonstration namespace and starts the App's multi-strategy host through the Linux process harness. It reads locally generated Bybit V5 frames through a TLS WebSocket. The result includes the MD PID and two distinct worker PIDs. After both have joined, the fixture publishes sequence 1000000. Both checkpoints must contain that quote and a positive number of user callbacks. The fixed Bybit prices of 100.0 and 100.1 USDT per BTC appear as 1000 and 1001 ticks. Each worker's command is disabled, the policy has no grant or lease and the example starts no private sender.

With `--keep`, the printed directory contains `market.json`, the binary descriptor in `control/spot-market.active`, `strategies.json` and `w1/` and `w2/` with separate host, bootstrap and parameter files. Each worker's `commands/merged-inputs/HEAD.json` references its own persisted checkpoint. `result.json` summarizes those checks. Without `--keep` the temporary state is removed after the processes exit.

```sh
python3 scripts/run-two-strategies.py --venue okx
python3 scripts/run-two-strategies.py --venue okx --live
```

In live mode TLS authenticates the public hostname using system trust. The optional `--proxy IP:PORT` selects an HTTP CONNECT proxy. Each worker reports a quote from its own checkpoint, which may be at a different sequence. A missing or unreachable feed makes the demonstration time out. The demonstration's account baseline is a local fixture and supplies no private venue facts.

## Start just the market-data owner

On Linux with Python 3.11 or later, run the following from the workspace root. Choose a new directory with a short pathname for the Unix socket.

```sh
cargo build -p tickwire-md
python3 crates/tickwire-md/examples/prepare-spot-market.py bybit /tmp/tw-bybit-demo --binary target/debug/tickwire-md
target/debug/tickwire-md --spot-market /tmp/tw-bybit-demo/market.json
```

Use `okx` and a different directory for BTC-USDT on OKX. The script accepts `--proxy 127.0.0.1:7890` if the host uses an HTTP CONNECT proxy. TLS still authenticates the exchange hostname. These examples initialize an isolated local namespace and example catalog for public observation. Production launchers supply their approved identities, instrument catalog and resource generations.

`spot_market_started` reports the topic and the exported `control/spot-market.active` header. A strategy reads `MarketView::best_quote()`. The quote holds ticks and lots. An absent, crossed or disconnected quote makes the feed unavailable. A fresh header alone carries no live price.

For a deployment, configure each worker's `Bootstrap.external_market` with the owner's socket, exact active header, catalog hash and instrument-set version, and assign a distinct worker identity, cursor and request ID. The host writes an admission for the actual child PID and the existing authenticated JOIN transfers the shared-memory handles. The `--client` helper builds a connector configuration from a client template and the active header. [Client template](exec-client.json)

One execution/account process can host several strategy slots against that topic. Set the deployment's `strategy` field to the following shape, with absolute paths to the two real host profiles. Each slot ID must match its bootstrap. An independent account risk domain runs a separate `tickwire-app run --config ...` process. `tickwire-app inspect --config ...` checks the group and prints its domain, instances and generations before launch. [Strategy group](../../tickwire-app/examples/shared-market-strategies.json)

After an abrupt process exit, confirm the former owner has exited before cleaning up its stale Unix socket, or use a fresh socket pathname with the same control directory. On an owner restart, advance both the ring epoch and the feed generation in the approved ResourceSpec. The control ledger retains the most recently published header and rejects reuse. Consumers must JOIN the new bank. The public spot owner does not enable private trading.
