## 忠实度与边界

Init 与 22 个动作均有源码对应，每组 23 个覆盖入口都有生成状态。所选源码入口为 Persistence.put_object/publish/verify/check 和 FileBlobStore.open/get/put_sync；模型覆盖这 7 个入口中与文件可见性、完成点、固定键内容和返回能力有关的分支。源码锚点使用仓库相对路径并单独锁定。

字节解码、DAG、对象长度/hash、输入覆盖及业务授权抽象为相应成功/失败出口，具体规则由 Rust 回归验证。多个对象位于同一个独占目录，没有删除 API；本级不包含 GC、多 pin 所有者、跨目录写入、签名或存储成功同步后介质丢失。能力交付结论以这些当前服务契约为前提。
