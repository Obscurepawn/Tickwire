# 后续范围

AccountGateway 的候选账户、首次输出、零接受中止和成交回报接线使用独立组合模型。账户日志的追加收据只说明对应记录及其物理前缀已同步，既不验证 AdmissionImage 的风险计算，也不完成交易所发送。

当前有限输入只包含 Admit 与 Aborted。其它六类 RecoveryRecord 的有序保存仍走同一代码入口，但金额、去重、费用和外部归属的状态变化不在本级结论内。现有账户模型及 Rust 恢复测试承担这些检查。

物理帧、段轮换与 manifest 事务，以及 SHA-256 的字节实现均未在本级重新证明。required 指向独立可信的物理前缀；没有 required 时，单个日志文件无法区分“从未存在的尾部”与介质在成功同步后静默丢失的完整尾部。本级只注入约定的未同步尾部损失。

2026-10-20 源码同步：账户将恢复附加 Unknown 与真实订单观察分开，重复成交的观察计数不再依赖本地冻结。本级只重放 Admit/Aborted，没有引入该问题的成交或终态观察；有效 Unknown 和所选记录的账本序号保持相同。只更新源码行号注释与锚点，未重跑 TLC，原统计保留。[同步记录与原始材料](../../../../docs/validation/account-recovery-metadata/sync.md)。
