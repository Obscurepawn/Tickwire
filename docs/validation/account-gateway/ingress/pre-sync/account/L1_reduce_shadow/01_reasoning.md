# 转录与性质

这组具体参数把资本公式化为 `abs(position) + Σremaining + Σceil(remaining/2) + Σpast_fee`。`past_fee=max(0,ceil(filled/2)+2-paid)`，费用关闭或订单中止后该项为零。资产侧费用预留为 `max(0,ceil(filled/2)+ceil(remaining/2)+2-paid)`。两者分别沿源码计算，未把费用在资本中扣除两次。

新增数量 1 的订单增加资本 4（本金 1、未来费用 1、舍入尾额 2），因此记录 H=4 和费用覆盖额度 3。只有没有任何确认、成交、费用、未知状态的可信中止才能移除 H。成交、普通终态与费用对账均保留 H；实际费用先消耗覆盖额度，超过部分再记入 D。影子余额为 `max(0,A0-ΣH-D)`，不随本地释放的资本自动增长。

减仓 admission 只读取当前实际仓位减去已有额度，未成交的开仓单不能提供额度。成交更新实际仓位、归属和本单额度后，再检查所有剩余额度是否超过实际仓位。外部仓位更新保留矛盾额度并冻结，实际结果不会为了维持非负不变量而被丢弃。

模型保留 ACK 后中止拒绝、中止后 ACK/成交/费用冻结、终态缺失成交详情、重复成交携带 Unknown 或终态、费用为零仍证明订单存在。终态累计小于后来实际成交时冻结来自本轮真实 Rust 回归修复。完全重复不重复现金或仓位；冲突保留原记录并冻结。

性质包括：未冻结账户资本和资产预留有资金覆盖；未冻结账户减仓总额度不超过实际仓位；钱包与仓位归属守恒；成交和费用只记一次；缺失详情不释放额度；H 不因成交或普通终态释放；零费用和 ACK 阻止中止；矛盾终态或 Unknown 冻结。模型检查的是这组有限输入的转录，没有把任意价格、保证金档位或真实交易所履约能力设为已证明结论。

有限输入中的 Fill 带空的内嵌费用列表和正常已确认、非终态订单观察；一次 Fill 动作涵盖 apply_fill 与 observe 的完整调用。Fee、Terminal 动作表示随后独立到达的事件，没有把单个事件内部步骤拆成可交错动作。
