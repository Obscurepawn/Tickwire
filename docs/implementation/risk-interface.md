# 风险计算模块接口

`tickwire-risk` 实现风险设计中的整数运算和准入公式，不读取网络、时钟、文件或账户凭证。调用者向函数传入已确认的账户事实与版本化参数，再由单写执行器提交结果。所有公式以 `Result<T, RiskError>` 返回，错误不会产生候选金额。

| 模块 | 输入与输出 | 状态边界 |
|---|---|---|
| `fixed` | `Fixed { atoms: i128, scale: u8 }`；精确解析、显式转换、向上/向下乘除 | 值不可变；scale 为 0..38，超精度、溢出、零除稳定拒绝 |
| `spot` | 部分成交、三类费用、第三币费用估值、基线可用额 | 按单币计算；BNB 估值与独占池分别输出 |
| `futures` | 单向/双向敞口、档位、抵押、资本、退出费与资金费 | 公式只产生候选结果；不伪造交易所账户事实 |
| `reservation` | 带 `AssetId` 的资金账本、减仓分配、影子上限 | `&mut self` 保证同一账本串行提交；失败保留余额与既有预留 |
| `settlement` | 到期通知、去重收入、完整账户对账证明 | 计时器只进入等待；对账闭合才更新持仓并释放费用余量 |

`Fixed` 的 scale 表示小数位，价格 tick 和数量 step 通过显式 `quantize` 验证与取整。相同值不同 scale 必须先 `rescale`；加减拒绝 scale 不一致。乘法消去十进制公共因子后使用 checked i128 中间值；若剩余中间值仍溢出则拒绝。负数除法基于商余数，支持 `i128::MIN`，不使用 `n+d-1` 或未经检查的绝对值。

公式字段名明确单位，单次计算固定同一数量、价格和计价币约定；跨币资金状态使用 `Money { asset, value }`，拒绝不同资产相加或预留。价格和数量的乘积允许调用者指定目标金额 scale。参数校验拒绝负数量、非正价格、负费率、非法杠杆、档位缺口与不连续维护金额。抵押资格失效只把正资产计零；负债始终按高估值扣除。

资本函数接受订单切片，逐单计算损失及执行费，保持不抵扣未确认未来收入的规则。退出量来自最坏仓位包络。账户与策略的归属计算相互独立，策略减仓不能直接视为账户减仓。未知订单继续占用；超时接口不释放资源。

执行器须校验输入版本、行情与账户新鲜度、产品模式、收费资格及订单身份，再调用本模块。真实执行器还须将成功预留与日志提交、最终发送门禁绑定。该库不把数值计算成功解释为发送授权。

开发顺序为接口定义、失败测试、实现、固定契约。数值回归读取 `specs/contracts/risk-vectors-v1.json` 的输入，调用公开函数后逐字段比较 21 个向量的 131 个预期字段。实现不得读取或回显 expected 数据。
