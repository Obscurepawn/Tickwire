# Symbolic SMT & arena framing notes — `L4_SymSimdCrcBmc`

- **Why `u128` `gcd`-reduced fallback in `StepSpec` is required**: When `mantissa * step_den` exceeds `u64::MAX` on large 19-digit mantissas near `i64::MAX`, `StepSpec` reduces `(scale_power, step)` by `gcd` in `u128` before dividing and checking `<= i64::MAX`, preserving exact parity with `Decimal` + `feed::units` (`crates/tickwire-md/src/spot_quotes/simd_json.rs:523-621`).
- **4KiB header + 64B block-span arena invariant**: `ShmArenaReader::read_retained_payload` verifies `block_cnt > 0`, `payload_len > 0`, `payload_len <= block_cnt * 64`, and `block_idx + block_cnt <= total_blocks` against the 4096-byte `verify_arena_header` layout (`crates/tickwire-strategy-sdk/src/arena.rs:72-210,439-502`), eliminating out-of-bounds SHM slice construction.
