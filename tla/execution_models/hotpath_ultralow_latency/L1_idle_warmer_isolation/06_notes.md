# Review and Phase-2 source-audit notes — `L1_IdleWarmerIsolation`

1. **Why live TLS sessions must never be warmed via discarded writes**: TLS 1.2 and TLS 1.3 AEAD ciphers derive per-record nonces monotonically from each endpoint's local sequence counter. Calling `rustls::ClientConnection::writer().write(...)` and discarding the resulting `write_tls` bytes increments `tx_nonce` on the client while leaving the venue server's `peer_expected_nonce` unchanged (`DemonstrateForbiddenLiveTlsDiscardContrast`), guaranteeing an immediate `bad_record_mac` alert on the very next live order.
2. **Complete isolation via `TlsLoopbackWarmer` and scratch dry-runs**: `TlsLoopbackWarmer` (`crates/tickwire-transport/src/warmup.rs:218-419`) pairs a private in-memory `ClientConnection` and `ServerConnection` (`server.send_tls13_tickets = 0`, 16 KiB buffer cap) over a 2 KiB stack scratch slice with zero syscalls, zero steady-state heap allocations, and zero reference to live sockets. Execution dry-runs (`crates/tickwire-spot-execution/src/warmup.rs:209-486`, `crates/tickwire-binance-execution/src/warmup.rs:190-427`) exercise HTTP/WS reply decoders, read-only `StpBook` views, cloned scratch `Account` instances, and scratch HMAC-SHA256 buffers without touching live `Account`, `AccountJournal`, `Origins`, SHM `published`, or `VenueRateLimiter` tokens (`LiveBusinessStateInvariance`, `LiveTlsNonceSynchronization`).
3. **Strict idle-window and in-flight suppression**: When `warmup_interval_ns == 0`, warming is unconditionally disabled (`warm_count == 0`); when `warmup_interval_ns > 0`, `WarmupTracker::record_activity` (`crates/tickwire-transport/src/warmup.rs:124-175`) resets the idle timer on every live market or order event, and `RestSession::maybe_warm_hot_path` (`crates/tickwire-spot-execution/src/session.rs:1901-1958`) plus `Runner::maybe_warm_hot_path` (`crates/tickwire-spot-runner/src/lib.rs:1179-1231`) additionally suppress warming whenever any request or reply is in flight (`WarmupStrictlyRespectsIdlePolicy`).
