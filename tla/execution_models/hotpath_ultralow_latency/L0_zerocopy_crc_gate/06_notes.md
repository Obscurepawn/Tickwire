# Review notes — `L0_ZeroCopyAndCrcGate`

- **Pure stateless SHM scope**: In Tickwire's stateless 3-process SHM architecture (zero local WAL/journal), durability is recovered from authenticated exchange REST snapshots; hot-path memory safety depends strictly on `RecordBorrow` lifetime pinning against `RELEASED` watermarks (`crates/tickwire-shm/src/mapped.rs:825-952`) and release-gated `ShmArenaWriter` reclamation (`crates/tickwire-strategy-sdk/src/arena.rs:291-386`).
- **Bit-flip guard scoping**: `InjectBitFlipWhenCrcEnabled` injects single-bit corruptions on unborrowed published slots and their owned arena blocks (`arena_blocks[b].owner_seq = ring_slots[s].seq`), verifying deterministic checksum rejection upon subsequent `ConsumerValidateZeroCopyAndArena` without violating Rust's read-only aliasing precondition on already-validated borrows.
- **Unbounded sequence lifting**: `RingCapacity = 2` and `MaxRingSeq = 3` exercise full wraparound and arena block reuse; unbounded `RingCapacity >= 2` and 64-bit sequences `1 .. SEQUENCE_LIMIT` are proved inductively in [../L3_sym_ring_warmer_inductive/05_output.md](../L3_sym_ring_warmer_inductive/05_output.md).
