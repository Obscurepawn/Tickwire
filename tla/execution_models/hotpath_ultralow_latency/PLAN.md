# Ultra-low-latency hot-path optimizations: zero-copy SHM `RecordBorrow` & retained arena lifetime safety, compile-time `crc32` gate, isolated ORS idle cache/TLS warming, SIMD JSON BBO decoding, and all-profile overflow trapping

This six-level model family (`L0`–`L2` explicit-state TLC + `L3`–`L5` dual-engine Apalache/Z3 symbolic induction & 64-bit/128-bit SMT BMC) formally verifies all hot-path latency and safety optimizations across the pure stateless 3-process shared-memory topology (`tickwire-md` + `tickwire-strategy-worker` + unified ORS execution process):

1. **`L0_zerocopy_crc_gate` (`L0_ZeroCopyAndCrcGate`)** — Verifies zero-copy `#[repr(C)]` `MarketRecord` / `IntentRecord` borrows over `tickwire-shm::RecordBorrow`, release-watermark-gated `ShmArenaWriter` / `ShmArenaReader` retained payload reclamation (`ArenaBorrowLifetimeSoundness`), and the compile-time `crc32` feature gate (`CrcEnabled = FALSE` default vs. `CrcEnabled = TRUE`). Models multi-consumer SPMC `broadcast_ring` slot publication, consumer `RecordBorrow` pinning, producer watermark-gated slot and arena-block reclamation, `RecordHeader` flag `0x08` (`CHECKSUM_PRESENT`) + `record_crc32c` / `payload_crc32c`, slot/arena bit-flip rejection when `CrcEnabled = TRUE`, and invalid/unaligned cast rejection.
2. **`L1_idle_warmer_isolation` (`L1_IdleWarmerIsolation`)** — Verifies side-effect-free ORS hot-path execution cache warming (`BinanceHotPathWarmer`, `UtaHotPathWarmer`, `AccountSession` `dry_run` short-circuit) and offline in-memory loopback `rustls` warming (`TlsLoopbackWarmer`). Models `warmup_interval_ns` (`0` disabled vs. `> 0` enabled), interleaved live market ticks, ORS order admissions, TLS wire sends, venue acknowledgements, and application pings alongside `WarmHotPath` (scratch JSON/frame decode, scratch `AccountSession` `dry_run` admission / read-only `StpBook` check, scratch HMAC-SHA256 signing, and isolated `dummy_client <-> dummy_server` TLS 1.3 AEAD record nonces), proving `WarmHotPath` never mutates live business, open-order, sequence-floor, rate-limiter, or live TLS session state.
3. **`L2_simd_decode_overflow` (`L2_SimdDecodeAndOverflowGuard`)** — Verifies the audited SIMD JSON BBO structural scanner + fixed-point decimal parser against the `serde_json` + `Decimal` / `feed::units` oracle in `tickwire-md` and workspace-wide `overflow-checks = true` across `dev`, `test`, `release`, and `bench` profiles (`Cargo.toml:57-69`). Models canonical unescaped BBO frames spanning SIMD chunk boundaries, reordered/whitespace JSON, escaped strings (`\"`, `\uXXXX`), chunk-boundary truncations, extra book levels, off-grid `price % tick_size != 0` / `qty % lot_size != 0`, crossed/zero-spread (`bid >= ask`) and one-sided snapshots (`Publication::Unavailable` vs. `Publication::Quote`), timestamp/mantissa overflows, zero steady-state heap allocations, and trapping fixed-point arithmetic near integer boundaries.
4. **`L3_sym_ring_warmer_inductive` (`L3_SymRingWarmerInductive`)** — Removes `L0`'s finite `RingCapacity = 2`, `MaxRingSeq = 3` bounds and `L1`'s `MaxNow = 5`, `MaxLiveOrders = 2`, `MaxWarmRuns = 2` caps via Apalache/Z3 Mode S2 Symbolic Inductive Invariants (`IndInv` + 4 CTI lemmas + Skolem consumer projection `c_star` + relational `ConstInit`) and Mode S1 64-bit `u64` BMC (`k = 6`). Proves `ZeroNoAliasWhileBorrowed` and `WatermarkMonotonicOrder` across all `RingCapacity >= 2` and `1 <= seq <= SEQUENCE_LIMIT`, plus `LiveBusinessStateInvariance`, `LiveTlsNonceSynchronization`, `DummyLoopbackTlsPairSynchronization`, `WarmupStrictlyRespectsTrackerPolicy`, and `DisabledWarmupNeverFires` across $\forall k \ge 0$ and full `0 .. 2^64 - 1` monotonic/jittered clocks.
5. **`L4_sym_simd_crc_bmc` (`L4_SymSimdCrcBmc`)** — Removes `L2`'s discrete buffer lengths and toy fixed-point ranges via Apalache/Z3 Mode S1 64-bit/128-bit `QF_LIA` BMC (`k = 6`) and Mode S2 unbounded block-scan induction (`IndInv`). Proves zero OOB vector/SWAR/scalar loads and `< 64` shifts across all `0 <= frame_len <= 65536` (`ZeroVectorOobAndValidShift`), exact mathematical equivalence between `simd_json::parse_positive_units` + `StepSpec` (`u64` + `u128` `gcd`-reduced fallback) and `Decimal::parse` + `feed::units` across full 19-digit mantissas up to `i64::MAX = 2^63 - 1` (`FastVsOracleExactEquivalence`), full 64-bit `millis.checked_mul(1_000_000)` overflow trapping (`NoSilentArithmeticWrap`), and exact 4096-byte SHM arena header + 64-byte block-span bounds (`ArenaHeaderAndBlockBoundsExact`).
6. **`L5_sym_warmer_crc_fix_validation` (`L5_SymWarmerCrcFixValidation`)** — Post-fix symbolic inductive and 64-bit `u64` BMC validation proving across $\forall k \ge 0$ (`IndInv`), Mode S1 BMC (`k = 6`), and finite TLC (`WarmupInterval = 2` & `WarmupInterval = 0`, `15/15` coverage entries) that: (1) ORS `RespWorker` / `WarmupTracker` idle polling preserves strictly positive wait intervals (`step_wait_ns > 0`) on non-runnable turns (`NoZeroWaitSpinWhenNotReady`), (2) `WarmupTracker::next_due_ns` (`anchor.checked_add(warmup_interval_ns)`) satisfies `can_warm(t) <=> next_due_ns().is_some_and(|due| t >= due)` across `0 .. 2^64 - 1` (`ExactNextDueCanWarmBiconditional`), and (3) cold-startup `CLOCK_MONOTONIC` seeding enforces `warm_count > 0 => now_ns - startup_clock_ns >= WarmupInterval` (`ColdStartupWaitsFullInterval`).
