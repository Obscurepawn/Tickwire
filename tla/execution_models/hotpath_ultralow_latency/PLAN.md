# Ultra-low-latency hot-path optimizations: zero-copy SHM `&MarketRecord`, compile-time `crc32` gate, isolated idle cache/TLS warming, SIMD JSON BBO decoding, and all-profile overflow trapping

This three-level model family formally verifies all five hot-path latency and safety optimizations across shared-memory IPC, physical WAL recovery, network transport & execution idle warming, public spot BBO JSON decoding, and workspace-wide checked arithmetic:

1. **`L0_zerocopy_crc_gate` (`L0_ZeroCopyAndCrcGate`)** — Verifies Optimization #1 (compile-time `crc32` feature gate with default OFF across `tickwire-ipc` and `tickwire-journal`) and Optimization #5 (`#[repr(C)]` `MarketRecord` 512-byte / 8-byte-aligned pure-integer wire layout + lifetime-pinned `&MarketRecord` zero-copy borrow over `tickwire-shm::RecordBorrow`). Models multi-consumer SPMC `broadcast_ring` slot publication, consumer `RecordBorrow` pinning, producer watermark-gated slot reclamation, `RecordHeader` flag `0x08` (`CHECKSUM_PRESENT`) + `record_crc32c` / `payload_crc32c`, and `tickwire-journal` WAL batch framing (`header_crc32c`, `payload_crc32c`, `frame_hash` SHA-256 chain, `repeated_total_len`, `end_magic`) under both `CrcEnabled = FALSE` and `CrcEnabled = TRUE` with torn-tail crashes, sealed-frame bit flips, slow-consumer lag, and invalid/unaligned cast probes.
2. **`L1_idle_warmer_isolation` (`L1_IdleWarmerIsolation`)** — Verifies Optimization #2 (side-effect-free hot-path execution cache warming and offline in-memory loopback `rustls` warming via `TlsLoopbackWarmer`). Models `warmup_interval_ns` (`0` disabled vs. `> 0` enabled), interleaved live market ticks, order admissions, TLS wire sends, venue acknowledgements, and application pings alongside `MaybeWarmHotPath` (scratch quote decode, scratch `Account` / read-only `StpBook` check, scratch HMAC-SHA256 signing, and isolated `dummy_client <-> dummy_server` TLS 1.3 AEAD record nonces), plus a contrast guard proving why discarding ciphertext on a live `rustls::ClientConnection` causes `bad_record_mac` desynchronization and verifying `WarmHotPath` never touches live business or TLS session state.
3. **`L2_simd_decode_overflow` (`L2_SimdDecodeAndOverflowGuard`)** — Verifies Optimization #3 (audited SIMD JSON BBO structural scanner + fixed-point decimal parser with `serde_json` oracle equivalence) and Optimization #4 (workspace-wide `overflow-checks = true` across `dev`, `test`, `release`, and `bench` profiles). Models canonical unescaped BBO frames spanning SIMD chunk boundaries, reordered/whitespace JSON, escaped strings (`\"`, `\uXXXX`), chunk-boundary truncations, extra book levels, off-grid `price % tick_size != 0` / `qty % lot_size != 0`, crossed/zero-spread (`bid >= ask`) and one-sided snapshots (`Publication::Unavailable` vs. `Publication::Quote`), timestamp/mantissa overflows, zero steady-state heap allocations, and trapping fixed-point arithmetic near integer boundaries.
