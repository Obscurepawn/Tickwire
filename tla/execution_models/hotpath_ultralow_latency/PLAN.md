# Ultra-low-latency hot-path optimizations: zero-copy SHM `&MarketRecord`, compile-time `crc32` gate, isolated idle cache/TLS warming, SIMD JSON BBO decoding, and all-profile overflow trapping

This six-level model family (`L0`–`L2` explicit-state TLC + `L3`–`L5` dual-engine Apalache/Z3 symbolic induction & 64-bit/128-bit SMT BMC) formally verifies all five hot-path latency and safety optimizations and post-audit boundary fixes across shared-memory IPC, physical WAL recovery, network transport & execution idle warming, public spot BBO JSON decoding, and workspace-wide checked arithmetic:

1. **`L0_zerocopy_crc_gate` (`L0_ZeroCopyAndCrcGate`)** — Verifies Optimization #1 (compile-time `crc32` feature gate with default OFF across `tickwire-ipc` and `tickwire-journal`) and Optimization #5 (`#[repr(C)]` `MarketRecord` 512-byte / 8-byte-aligned pure-integer wire layout + lifetime-pinned `&MarketRecord` zero-copy borrow over `tickwire-shm::RecordBorrow`). Models multi-consumer SPMC `broadcast_ring` slot publication, consumer `RecordBorrow` pinning, producer watermark-gated slot reclamation, `RecordHeader` flag `0x08` (`CHECKSUM_PRESENT`) + `record_crc32c` / `payload_crc32c`, and `tickwire-journal` WAL batch framing (`header_crc32c`, `payload_crc32c`, `frame_hash` SHA-256 chain, `repeated_total_len`, `end_magic`) under both `CrcEnabled = FALSE` and `CrcEnabled = TRUE` with torn-tail crashes, sealed-frame bit flips, slow-consumer lag, and invalid/unaligned cast probes.
2. **`L1_idle_warmer_isolation` (`L1_IdleWarmerIsolation`)** — Verifies Optimization #2 (side-effect-free hot-path execution cache warming and offline in-memory loopback `rustls` warming via `TlsLoopbackWarmer`). Models `warmup_interval_ns` (`0` disabled vs. `> 0` enabled), interleaved live market ticks, order admissions, TLS wire sends, venue acknowledgements, and application pings alongside `MaybeWarmHotPath` (scratch quote decode, scratch `Account` / read-only `StpBook` check, scratch HMAC-SHA256 signing, and isolated `dummy_client <-> dummy_server` TLS 1.3 AEAD record nonces), plus a contrast guard proving why discarding ciphertext on a live `rustls::ClientConnection` causes `bad_record_mac` desynchronization and verifying `WarmHotPath` never touches live business or TLS session state.
3. **`L2_simd_decode_overflow` (`L2_SimdDecodeAndOverflowGuard`)** — Verifies Optimization #3 (audited SIMD JSON BBO structural scanner + fixed-point decimal parser with `serde_json` oracle equivalence) and Optimization #4 (workspace-wide `overflow-checks = true` across `dev`, `test`, `release`, and `bench` profiles). Models canonical unescaped BBO frames spanning SIMD chunk boundaries, reordered/whitespace JSON, escaped strings (`\"`, `\uXXXX`), chunk-boundary truncations, extra book levels, off-grid `price % tick_size != 0` / `qty % lot_size != 0`, crossed/zero-spread (`bid >= ask`) and one-sided snapshots (`Publication::Unavailable` vs. `Publication::Quote`), timestamp/mantissa overflows, zero steady-state heap allocations, and trapping fixed-point arithmetic near integer boundaries.
4. **`L3_sym_ring_warmer_inductive` (`L3_SymRingWarmerInductive`)** — Removes `L0`'s finite `RingCapacity = 2`, `MaxRingSeq = 3` bounds and `L1`'s `MaxNow = 5`, `MaxLiveOrders = 2`, `MaxWarmRuns = 2` caps via Apalache/Z3 Mode S2 Symbolic Inductive Invariants (`IndInv` + 4 CTI lemmas + Skolem consumer projection `c_star` + relational `ConstInit`) and Mode S1 64-bit `u64` BMC. Proves `ZeroNoAliasWhileBorrowed` and `WatermarkMonotonicOrder` across all `RingCapacity >= 2` and `1 <= seq <= 2^63`, plus `LiveBusinessStateInvariance`, `LiveTlsNonceSynchronization`, `DummyLoopbackTlsPairSynchronization`, `WarmupStrictlyRespectsTrackerPolicy`, and `DisabledWarmupNeverFires` across $\forall k \ge 0$ and full `0 .. 2^64 - 1` monotonic/jittered clocks, while surfacing three Z3 boundary/scheduling diagnostics (`CoreNode` `!node_ready` `0ns` poll spin, cold-startup unseeded `anchor == 0`, and `u64::MAX` `next_due_ns` saturation).
5. **`L4_sym_simd_crc_bmc` (`L4_SymSimdCrcBmc`)** — Removes `L2`'s 7 discrete buffer lengths and toy fixed-point ranges plus `L0`'s abstract CRC flag boolean via Apalache/Z3 Mode S1 64-bit/128-bit `QF_LIA` BMC and Mode S2 unbounded block-scan induction. Proves zero OOB vector/SWAR/scalar loads and `< 64` shifts across all `0 <= frame_len <= 65536` (`ZeroVectorOobAndValidShift`), exact mathematical equivalence between `simd_json::parse_positive_units` + `StepSpec` (`u64` + `u128` `gcd`-reduced fallback) and `Decimal::parse` + `feed::units` across full 19-digit mantissas up to `i64::MAX = 2^63 - 1` (`FastVsOracleExactEquivalence`), full 64-bit `millis.checked_mul(1_000_000)` overflow trapping (`NoSilentArithmeticWrap`), and exact `crc32c_masked` 8B/64B slice partitioning across arbitrary/inverted/OOB `Range<usize>` (`CrcMaskedSlicePartitionExact`).
6. **`L5_sym_warmer_crc_fix_validation` (`L5_SymWarmerCrcFixValidation`)** — Post-fix `/vibe-tla fix` symbolic validation closing all four 64-bit boundary, scheduling, and API-parity findings surfaced by `L3` and `L4`. Proves via Apalache/Z3 Mode S2 Symbolic Inductive Invariants (`IndInv`, $\forall k \ge 0$), Mode S1 64-bit `u64` BMC (`k = 8`), and finite TLC (`WarmupInterval = 2` & `WarmupInterval = 0`, `16/16` coverage entries) that: (1) `CoreNode::step_inner` + `run_with` guarantees `step_wait_ns > 0` on every non-runnable turn including unready/frozen/halted states and transient warmup errors (`NoZeroWaitSpinWhenNotReady`), (2) `WarmupTracker::next_due_ns` (`anchor.checked_add(warmup_interval_ns)`) satisfies `can_warm(t) <=> next_due_ns().is_some_and(|due| t >= due)` across `0 .. 2^64 - 1` (`ExactNextDueCanWarmBiconditional`), (3) cold-startup `CLOCK_MONOTONIC` seeding enforces `warm_count > 0 => now_ns - startup_clock_ns >= WarmupInterval` (`ColdStartupWaitsFullInterval`), and (4) `tickwire_journal::crc32c::crc32c_masked` and `tickwire_ipc::crc32c_masked` clamp arbitrary/inverted/OOB `Range<usize>` inputs without panics and hash identical effective byte streams (`TotalCrc32cMaskedParity`).
