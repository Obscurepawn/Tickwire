# Review and Phase-2 source-audit notes — `L2_SimdDecodeAndOverflowGuard`

1. **Two-stage BBO decode vs. publication contract**: In `crates/tickwire-md/src/spot_quotes/protocol.rs:84-241` and `crates/tickwire-md/src/spot_quotes.rs:80-241`, `Session::on_text` returns `Ok(Some(Quote))` on valid one-sided (`[]`) or crossed/zero-spread (`ask_ticks <= bid_ticks`) snapshots without marking `session.failed = true`, and `Quote::publication` subsequently converts missing-side or crossed quotes into `Publication::Unavailable` to invalidate stale downstream observations. `L2_SimdDecodeAndOverflowGuard` explicitly models and verifies both stages (`ExactOracleEquivalence` + `TickLotAndPositiveSpreadSoundness`).
2. **SIMD structural scan safety, rollback cleanliness, & RFC 8259 fallback**: Unaligned vector loads (`16`B SSE2/NEON, `32`B AVX2 in `crates/tickwire-md/src/spot_quotes/simd_json.rs:285-469`) execute only while `offset + chunk_width <= len`, zero-extending `u32 as u64` movemasks and handling tail bytes via SWAR/scalar code (`simd_oob_reads == 0`). Any backslash (`\"`, `\uXXXX`) or non-ASCII byte (`>= 0x80`) aborts via `ScanAbort::Fallback` before `decode_bybit` / `decode_okx` (`crates/tickwire-md/src/spot_quotes/simd_json.rs:1285-1574`) commits `*acknowledged = true`, delegating cleanly to the zero-heap borrowed `serde_json` fallback so 100% of valid and invalid inputs match `bybit_serde_oracle` / `okx_serde_oracle` (`ExactOracleEquivalence`).
3. **All-profile `overflow-checks = true` & `StepSpec` `i128` fallback**: `crates/tickwire-md/src/spot_quotes/simd_json.rs:523-621` routes `u64` scaling overflows through an exact `i128` fallback matching `Decimal::parse` + `feed::units`, while root `Cargo.toml:14-26` sets `overflow-checks = true` across `[profile.dev]`, `[profile.test]`, `[profile.release]`, and `[profile.bench]` (verified by `crates/tickwire-journal/tests/overflow_checks.rs:1-57`), eliminating debug-vs-release/bench wrap divergence across fixed-point tick, lot, timestamp, and notional arithmetic (`NoSilentArithmeticWrap`).
