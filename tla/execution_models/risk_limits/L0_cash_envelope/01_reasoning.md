# Model regime

This is a faithful transcription for a single spot instrument, two authorized strategies, and one distinct admitted limit order per strategy. Both limits and executions use price one with exact integral units and zero fees. The configured maximum fill count is at least the maximum order quantity, so one-atom partials stay within the fill count bound. The catalog, risk revision, publisher, owner and time checks already permit new risk. The account has no unsettled external debits, no extra fee pool and no futures positions. Baseline locked balances equal nontrade locks, as required by the production caller’s single zero-coverage row. The unattributed bucket contains the residual after both strategies’ starting base ownership.

A serialized account owner builds a candidate with the new order, checks it, and changes the current account only on success. Every allocation of partial filled quantities is explored, along with a matched-cumulative terminal cancellation. Credits, debits and remaining order holds use the same exact scale, so the risk kernel’s checked integer operations cannot overflow at these bounds. The polynomial number of possible fill vectors lets the invariant judge every attainable future inventory directly, independent of the endpoint formulas used in the implementation. This check does not derive venue price improvement, ingress freshness, fee handling or decimal rounding.

The initial allocations are valid account snapshot inputs. The account sums the supplied signed rows and credits the residual to owner zero. Baseline totals and locks here are chosen to exercise the live risk routine, independently of how an adapter obtained a snapshot. Within each strategy's one-order budget all fills have the same direction, so positive and negative per-member net flow reproduce the account's separate accumulated credits and debits exactly.
