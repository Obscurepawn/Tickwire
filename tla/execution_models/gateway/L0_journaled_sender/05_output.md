# L0 结果

四组配置均 PASS，11 个不变量通过。检查对象是实际 `JournaledSender` 的日志、传输和恢复组合，包含二至三个意图、部分接受、门禁变化、同步失败、完整尾记录存活和最多两次崩溃。

在模型的可信服务与持久记录契约下，应用字节首次接受前，规范命令闭包和意图 WAL 已同步；首次授权紧接应用写入，零接受等待不保留许可。部分接受后的失败保留 Unknown，同一意图精确重试只读原状态。Aborted 只在完整中止记录可恢复后发布，且对应意图的历史接受数为零。恢复成功也不重建网络队列，始终冻结新的发送。

`AwaitingResponse` 只表示本机完整冲刷。门禁结论止于同步采样与 transport 截止检查；本级不证明网卡输出时刻仍有授权，也不把持久 Aborted 当作资金 reducer 已完成释放。真实风险与账户算法、签名参数映射、业务 ACK/成交关联、文件系统内部和恢复后激活属于后续或独立模块。

root、risk_core 与 market_core 已独立核对源码和模型，未发现开放候选。
