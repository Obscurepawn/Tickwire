# 发送协调验证阶梯

L0 对应 `JournaledSender`：准备规范命令并验证可信闭包、同步业务 WAL、排队、首次输出时重新取门禁、继续冲刷、记录零接受中止、冻结和恢复。协调器独占连接；Rust `&mut self` 使一个实例的公开变更调用串行。模型允许进程在调用内部崩溃，但不允许另一个 `submit`、`cancel` 或 `poll` 在同次调用内部重入。

本级接入 transport L0 的接受证据与 business_journal 的同步返回契约，验证两者在协调器中的调用顺序。网络握手、WouldBlock、部分接受、断连、同步失败，以及未收到同步回执的完整尾记录在恢复时存活，均属于所选故障范围。可信授权服务的风险与账户算法、协议编码器的签名及业务字段映射、TLS 密码学、文件系统内部持久化由对应模块负责。
