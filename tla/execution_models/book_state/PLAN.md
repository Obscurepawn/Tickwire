# Book 状态与知识语义验证计划

验证对象是 `tickwire-book` 的公开生命周期及读取结果。源码 SHA-256 固定为 `37beb8dcd515b76a8c3bec0a2cd46a1c3c2431375276810b45818b8b35fd04a3`。此前数组、批量定位和性能证据保持冻结，这个阶梯不重复证明排序算法。

## 调用与并发

`install_snapshot/apply/begin_rebuild/invalidate` 均借用 `&mut Book`；`view` 返回借用当前实例的 `BookView`，其借用仍被使用时，安全 Rust 不允许同时取得可变借用。模型把每次公开调用及其即时返回值作为一个完整动作，不拆成可相互竞争的数组写入。实际调用者目前是串行测试、基准和 `tickwire-mock/examples/spot-roundtrip.rs:25-52`；仓库没有生产 feed 到 strategy/risk gate 的集成适配器。

`view` 只在调用时检查年龄，`BookView.age_ns` 随后保持创建时值。`Live` 可以伴随 `BestLevel::Unknown`；有效 view 和足以使用的已知最优价是两个不同返回条件。模型不添加不存在的自动增险门，也不把过期视图自动失效当成源码行为。

## 阶梯

| 级别 | 新增关注点 | 具体状态与边界 |
| --- | --- | --- |
| L0_lifecycle | 生命周期、身份、序号与失败原子性 | generation、四种状态、快照/事件水位、接收时间、双侧内容见证；Spot/USD-M 分别配置 |
| L1_coverage | 已知与未知的价格内容 | 有限价格域、快照覆盖、明确更新和外侧隐藏价位；以实际内容见证检查 best/quantity 返回值 |
| 后续 | 行情管线与执行准入 | 等待真实适配器后再加入快照请求重试、跨连接 shadow 切换、增险 gate 与跨进程发布 |

L0 使用源码转录模式，直接枚举调用方可提供的旧身份、缺口、重复和非法批次结果。L1 引入与快照覆盖契约相容的外侧隐藏价位；没有网络队列、丢包算法或多线程调度器。每级单独运行有限主配置、扩展配置和边界配置，固定一 worker、启用动作覆盖。所有配置都实际运行，未触发的动作在关闭该级前处理。

## 交付与排除

每级使用 `00_input → 01_reasoning → 02_models → 03_run_log → 05_output`，附实际日志、配置、源码锚点和独立审阅。发现违反性质时先保留真实 trace 并核对遗漏保护；模型结果不代替 Rust 回归。顶层 TLA 索引由 root 汇总，新接口与契约说明放在独立文件，不修改已冻结的性能报告。

本阶梯不验证数组排序、二分与合并工作区、整数转换、网络解码、OS 借用实现或生产策略是否正确消费 `Unknown`。L0 将已验证批次的内容表示成有限见证值；L1 再精化价格知识，不能从 L0 的 PASS 推导具体价格查询正确。
