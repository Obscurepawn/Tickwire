# L0 结果

三组有限配置均 PASS：单订单 72 个不同状态，竞争资本 345 个，双订单两次崩溃 879 个。9 个不变量通过，23 个迁移动作全部产生后继状态。

在模型的受信服务和持久前缀契约下，发送调用之前已有该意图的持久闭包与同步日志；I/O 等待期间关闭时效门会阻止发送。零字节中止必须进入同步日志后才能释放预留。崩溃后按原事件顺序恢复，只有同步保存或恢复确认的完整 Aborted 事件允许释放；恢复过程中及完成后始终冻结。

root 与 ipc_codec 分别只读核对源码和模型，未发现阻断项。两个实现修正来自源码复核与真实行为 Red：接管后相同意图重试、同步等待期间期限变化；本级没有产生实现反例。
