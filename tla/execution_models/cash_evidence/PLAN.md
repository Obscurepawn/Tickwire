# Cash reconciliation evidence

The account owner serializes private observations, applies one completed REST scan, and records the fee decision. A REST worker issues two authenticated reads against the same start time. Socket capture and crash boundaries can occur while the account owner holds its input cut. The [terminal fee model](L0_terminal_fees/01_reasoning.md) checks what reaches the WAL under disagreement.

A later level can combine aged-out REST history with several accounts' independent fee assets and order lookups.
