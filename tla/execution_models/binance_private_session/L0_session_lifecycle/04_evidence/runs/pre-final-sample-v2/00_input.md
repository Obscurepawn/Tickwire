# L0 输入

核对源码 `crates/tickwire-binance-private/src/{lib,request,client,session}.rs`，接口、41项原生/Linux行为测试及两平台Clippy已完成，原始检查归验证目录。模型输入为实际单 owner、一个待确认请求、一个账户和固定认证模式。

使用允许断连、回复丢失/延迟、错误回复和提前事件的故障模式。代码仍负责失败关闭和重新建立连接；上层提供受信账户/API key 绑定、连接代次起点及 mandatory Clock adapter。

时间采用离散毫秒输入：`source_ns = model_ms × 1_000_000`。固定请求/签名窗口5,000 ms、key有效期3,600,000 ms、续期间隔1,800,000 ms、初始退避100 ms，均对应默认配置。量化测试输入只取创建时刻、续期时刻、截止时刻和同步许可后跨截止时刻，不声称覆盖1 ns边界。所有配置的代次/请求数是外部执行长度上限，不是源码计数器最大值；实际u64耗尽以Rust边界测试为证。
