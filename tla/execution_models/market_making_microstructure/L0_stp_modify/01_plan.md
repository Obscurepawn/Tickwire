# Modeling plan — `L0_StpModify`

## Scope and state owners
- **`StpBook` & `SymbolSlot`** (`crates/tickwire-account/src/stp_book.rs:45-103`, `crates/tickwire-account/src/stp_book.rs:174-395`, `crates/tickwire-account/src/stp_book.rs:443-450`): owns per-side order vectors (`buy_orders`, `sell_orders`), dual-price `aggressive_ticks` (`max(resting, pending)` for `Buy`, `min(resting, pending)` for `Sell`), `Vec::swap_remove` slot compaction + `recompute_best_bid`/`recompute_best_ask`, and O(1) `self_cross` / `self_cross_excluding` checks.
- **`Account` `Modify` & hold engine** (`crates/tickwire-account/src/modifications.rs:12-421`, `crates/tickwire-account/src/modifications.rs:459-928`, `crates/tickwire-account/src/calculation.rs:150-240`, `crates/tickwire-account/src/events.rs:770-896`): owns single-in-flight `PendingModify`, `ModificationRecord`, worst-case Spot quote/base holds and Futures `shadow_holds`, `client_id` tentative indexing and alias promotion, venue-clamped `observe_modified`, `abort_modification` / `reject_modification` rollback, and `supersede_pending_modify_on_terminal` when a fill or cancel closes an order mid-modify.
- **Execution gate, `QueryDesk`, & `AccountSession`** (`crates/tickwire-spot-execution/src/session.rs:1103-1185`, `crates/tickwire-spot-execution/src/session.rs:1300-1375`, `crates/tickwire-binance-account/src/session.rs:1986-2124`, `crates/tickwire-binance-account/src/session.rs:2885-3205`, `crates/tickwire-account/src/query_desk.rs:647-868`): own pre-wire local refusal non-burn (admitting on `OrsOrderManager` / `Account` before `RateLimiter` spend) and `AmendAmbiguous` per-order query resolution (including Spot two-phase `origClientOrderId = new_client_id` -> `-2013` fallback to `orderId`).

1. **`L0_StpModify.cfg` (Spot worst-case principal holds + multi-order `swap_remove` + Spot 2-phase `new_client_id` query)**: `BuyOrders = {1, 2}`, `SellOrders = {3}`, `ModifiableOrders = {1}`, `BuyPrices = {1, 2, 3}`, `SellPrices = {3, 4}`, `Qtys = {1, 2}`, `QuoteBalance = 8`, `BaseBalance = 3`, `FuturesMarginMode = FALSE`, `StpEnforced = TRUE`. Exercises Futures `shadow_holds` delta reservation, partial release under venue-clamped `Modified`, and full release on `Aborted`, `ModifyRejected`, and terminal superseding.
