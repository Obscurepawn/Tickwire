# State and Abstraction (`L0_OrsSessionRouting`)

- **Asymmetric multi-account authorization**: Two registered `AccountSession`s (`Accounts = {1, 2}`) and two strategies (`Strats = {1, 2}`) exercise every branch of `resolve_account_ref`: Strategy `1` is authorized for `{1, 2}` with default `1`, while Strategy `2` is authorized only for `{2}` with default `2`. Requesting `account_ref = 0` routes to `DefaultAccount(s)`; `account_ref = 3` triggers `INVALID_ACCOUNT_ID`; Strategy `2` requesting `account_ref = 1` triggers `REJECT_ROUTING_ID_MISMATCH`.
- **DOP sequence continuity & worker restarts**: `DopLogout` clears `logged_in[s]` and resets `last_recv_seq[s] = 0` while preserving `next_ord_seq[s]`. `DopLogin` computes `max(next_ord_seq[s], max(login_seq, 1))`, ensuring a restarted worker supplying a stale or zero `login_seq` never regresses `next_ord_seq[s]`. `ValidMsgSeq` enforces `msg_seqnum >= 1` and `mseq == last_recv_seq[s] + 1` once a baseline is established, rejecting gaps without advancing `last_recv_seq[s]`.
- **Per-order `RejectStaleOrder` gate**: `RejectStaleNewOrder` fires when `now_ns - create_ts > MaxOrderAgeNs`, advancing sequence cursors via `consume_rejected_new_order_seq` while mutating zero `AccountSession` holds and leaving `strat_enabled` untouched.
- **Ascending one-order-at-a-time disable sweep**: `AdminDisableAndStartSweep` clears matching `(account, strat)` entries (`acct_arg = 0` across all accounts; `strat_arg = 255` across all strategies) and sets `sweep_cursor = 1`. Each `AdminSweepNextSlot` step inspects only slot `k = sweep_cursor`, setting `cancel_on_ack = TRUE` on `PendingNew` or transitioning `Open` to `PendingAdminCancel` (`ADMIN_ACTION`) before advancing `sweep_cursor`. `VenueAckOrder` honors `cancel_on_ack`, proving race-freedom when an `Ack` arrives after `sweep_cursor` has already scanned past a `PendingNew` slot.
