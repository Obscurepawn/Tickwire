# State and Symbolic Abstraction (`L1_SymDualThreadSwitchover`)

- **Explicit spinlock ownership & deadlock-freedom**: `order_lock_holder`, `stp_lock_holder`, and `conn_lock_holder` track per-thread ownership across `"NONE"`, `"REQ"`, and `"RESP"`. `REQ` reads lock-free atomic `bbo_atomic_seq` (`OrsStpBook::self_cross`), acquires `LockedOrder -> OrsStpBook`, releases both before stack wire-frame encoding, and only then acquires `LockedConnection` (`ReqAcquireConnForSend`) or rolls back unsent `PendingNew` state (`ReqRollbackUnsentWhenRouteUnavailable`) if `active_published_ready` became `FALSE`. `RESP` acquires `LockedConnection` only during raw byte polling (`poll_raw_rx`), releases `LockedConnection` prior to protocol parsing, and only then acquires `LockedOrder -> OrsStpBook`. Native TLC deadlock checking remains enabled (`CHECK_DEADLOCK TRUE` default) alongside symbolic `SpinlockDeadlockFreedomInv`.
- **`DialBaton` deferred invalidation & token epoch**: `"tw-dialer"` claims `"Wanted"` when `now_ns >= baton_due_ns` and snapshots `token_epoch`. Concurrent `RotateTokenOrDeferBatonClose` models stream/auth token rotation or slot close requests; on `RespResetInvalidatedBaton` or `RespTakeReadyDiscardInvalid`, stale or close-requested `DialedLink`s are dropped without ever promoting to `standby_established`.
- **Short-write self-retire & `64008` graceful drain**: `ReqShortWriteRetireScheduleQuery` models `send_frame_nonblocking` latching `active_close_pending = TRUE`, unpublishing `active_published_ready = FALSE`, releasing `LockedConnection`, and scheduling `OrsQueryDesk` (`query_desk_pending = TRUE`). `RespHandleMaintenanceNotice64008` marks `active_draining = TRUE`, unpublishes `active_published_ready = FALSE`, triggers `DialBaton::want` in parallel, continues draining `active_inflight` on `RESP`, and permits `RespPromoteStandbyToActive` only once `active_inflight == 0`.
- **CTI strengthening**: Apalache 1-step induction surfaced one unreachable predecessor (`req_phase = "HoldConnSending" /\ ~active_established`), resolved by recording the invariant `(req_phase = "HoldConnSending") => (active_established /\ ~active_close_pending)` established when `ReqAcquireConnForSend` observes `active_published_ready` under `conn_lock_holder = "REQ"`.
