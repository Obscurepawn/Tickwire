# Review notes

1. **Dual-epoch bump on disconnect and reconnect**: `OrderRouter::on_disconnect` (`crates/tickwire-transport/src/order_router.rs:398-408`) and `OrderRouter::on_connected` (`crates/tickwire-transport/src/order_router.rs:378-396`) both advance `route.epoch` and reset `RouteHealth` (`inflight = 0, ema_us = 0, ema_samples = 0`). Any late `release_inflight(conn_id, old_epoch)` or `note_sample(conn_id, old_epoch, ...)` after disconnect or reconnect returns `Ok(false)` without mutating the new connection's `inflight` or EWMA score.
2. **Three-part `poll_pool_dials_filtered` invariant**: Installing a ready `DialBaton` link onto `conn_id` requires simultaneously (a) `pending_send.is_none()`, (b) `retained_receive.is_empty()` (`crates/tickwire-account-gateway/src/pool.rs:294-330`), and (c) session slot drain completion (`crates/tickwire-binance-account/src/session.rs:857-955`, `crates/tickwire-spot-execution/src/session.rs:417-470`).
3. **Single-point inflight release on `SendState::NoBytes`**: `AccountGateway::apply_slot_report` (`crates/tickwire-account-gateway/src/pool.rs:715-735`) calls `release_inflight(conn_id, epoch)` once when aborting a zero-byte `NoBytes` send, keeping `InflightAccountingExact` invariant across every epoch.
