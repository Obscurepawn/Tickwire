# Hot-Path Decoupling and Stateless Windowed Pools

Off-hot-path session dialing (`DialBaton` + `IpPool`) and asynchronous REST querying (`AsyncRestQuerier`) decouple blocking TCP/TLS handshakes, DNS/IP rotation, and bounded HTTP retries from the hot execution threads via lock-free SPSC rings and fine-grained `TimedSpinLock` batons. Inside `Account` and `AccountGateway`, fixed-capacity `WindowedTable` pools (`orders`, `management_admissions`) and associative `FillRecordPool` ways (`FILL_BUCKET_WAYS`) bound memory across multi-day uptime while protecting non-retirable orders, `TRADE_LITE` omitted-fee fills, post-trade `amendment` fee delta updates, duplicate intent/trade-ID deduplication windows, per-order `in_doubt` isolation, and unstarved `Cancel`/`Query` management headroom.
