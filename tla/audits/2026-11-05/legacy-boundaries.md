# Legacy market and submission model boundaries

Source review at `9b2ed63`. The November 5 inventory compares the frozen line hashes. This audit follows callers and compares the commits that changed their behavior. [Line-lock counts](inventory.md#previous-line-locks)

## Binance depth synchronization

Of 575 recorded lines, 356 differ at their former positions. Comparing the implementation in `2ab7b1a` with HEAD shows two changes in `c6ce8c6`. The coordinator allocates its book once in a box, and the JSON and new SBE entry points share `apply_update`. The JSON token check, bounded FIFO, snapshot retry and ordered bridge retain their previous transitions. The book crate itself changed one documentation link over this interval. L0's JSON sequencing results still apply at its decoded-event boundary. ## Binance private session

All 1,116 recorded lines match. The client, request and session source files are unchanged since `6c99661`. The v2 model still captures one request in flight, connection epochs, replies and a final clock sample after the quota callback but before the first accepted byte. Two changes in the public wrapper fall outside that state machine. Structure binding was added in `ae79799`, and `616bbdd` replaced the literal venue ID with the named constant of the same value. ## Submission and replay

L1 still describes dependency storage, commit, lost receipt and send authorization. All 269 line hashes match, yet its `Restart` restores each committed order as unknown with a full hold and an empty terminal set. Commit `8689804` made a zero-byte transport outcome append a durable abort before applying it. The current mock can replay that abort and release the hold after a crash. Commit `06d4f37` removed the replica-ready field and commit-profile argument. The current caller commits locally and presents the receipt before `begin_send`. [L1 restart](../../execution_models/submission/L1_crash_receipt/02_models/L1_CrashReceipt.tla#L177) · [Current commit and abort](../../../crates/tickwire-mock/src/lib.rs#L219)

L2's fixed revision `04351db` restores all committed intents before replaying its ordered list of economic facts. Since `8689804`, the mock replays a single stream of interleaved intent and fact records. An abort that releases capital before the next intent is a material difference. The old L2 results describe grouped replay. Use the subsequent ordered-abort model for the mock, and the business journal's own model for file-backed recovery.
