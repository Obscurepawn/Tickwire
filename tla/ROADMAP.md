# TLA+ & Apalache Model Family Roadmap

Each directory under `tla/execution_models/` binds **21 model families, 40 finite-state TLC specifications (`.tla` + `.cfg`), and 11 Snowcat-typed Apalache/Z3 symbolic inductive `IndInv` specifications (`L*_Sym*.tla`)** to concrete core-crate Rust source anchors (`44,618` SHA-256-locked source lines across `02_models/anchors.lock`), modeling assumptions, and verification logs. Run any individual family from the repository root with `./scripts/check-tla.sh <family>` (for example, `./scripts/check-tla.sh request_budget`).
